# Release Notes — v1.19.0

**Released**: 2026-11-26

Release Notes for Version 1.19.0

We are excited to announce the latest updates in version 1.19.0 of our software! This release focuses on enhancing user experience, improving security, and providing new features that will make managing identity and access more efficient and intuitive.

Highlights:

1. **Improved Verification Process**: We’ve added user-friendly verification pages that streamline the identity verification process. This feature ensures that our users can easily confirm their identities, fostering a smoother experience when accessing our services.

2. **Client Contracts**: Users can now access and manage client contracts effortlessly. The introduction of this feature allows for better tracking and organization of contractual obligations, ensuring clear communication and easier compliance.

3. **CLI Login Enhancement**: The Command Line Interface (CLI) now supports an easier login process. This improvement provides a more secure and accessible entry point for users managing their accounts remotely.

4. **Enhanced Security Measures**: We're committed to keeping your data safe. This release includes new security measures, such as locking accounts prior to password reset tokens and maintaining grants during session changes. These features help protect against unauthorized access, offering peace of mind to our users.

5. **Device Authorization Improvements**: We've made significant upgrades to device authorization processes, ensuring that users can verify devices with specific account boundaries. This boosts overall security while maintaining user convenience.

Overall, this release is designed to make your interactions with our platform more secure and user-friendly. We appreciate your continued support and look forward to bringing you more enhancements in the future!
